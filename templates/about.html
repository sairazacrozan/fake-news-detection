📚 Project Overview

About This Project

Fake News Detection Using Machine Learning & Natural Language Processing

A college-level machine learning and NLP application engineered to analyze textual patterns in news articles and classify them as authentic or misinformation.

🔍 NLP Preprocessing Pipeline

Input articles undergo thorough text normalization using NLTK and Python regular expressions:

  • Lowercasing and punctuation removal
  • Number and symbol filtering
  • Stopword removal using NLTK English corpus
  • Tokenization and whitespace normalization

⚙️ Feature Extraction

Normalized text is converted into high-dimensional numerical vectors using TF-IDF (Term Frequency-Inverse Document Frequency):

  • Vocabulary size: Top 5,000 informative features
  • N-gram range: Unigrams and bigrams (1, 2)
  • Sublinear term-frequency scaling

🤖 Trained Machine Learning Models

Four complementary classification algorithms were trained and evaluated on labelled benchmarks:

  • Logistic Regression: Probabilistic linear classification baseline
  • Multinomial Naive Bayes: Frequency-based probabilistic model
  • Random Forest: Ensemble decision tree architecture
  • Linear SVM: Maximum-margin hyperplane classifier

💾 Web & Database Architecture

Built using a modular software stack designed for demonstration and evaluation:

  • Backend: Flask microframework (Python 3)
  • Storage: Local SQLite database (database/history.db)
  • Analytics: Responsive Chart.js client-side visualizers
ℹ️
Scientific Notice: The system classifies news articles as FAKE or REAL based on patterns learned from labelled training data. The confidence score represents model statistical certainty relative to the dataset, not a factual guarantee of real-world truth.
